# How-to guides

Each guide shows how to do one thing with LETS. They assume you've installed it and set up a repo; if not, start with
the [tutorial](../tutorial.md).

| Guide | Read it when you want to |
|---|---|
| [Let the agent build](agent-mode.md) | have the agent write the code instead of pairing, or build in the background |
| [Make a small fix without planning](small-fixes.md) | fix a typo, refactor, bump a dependency or fix a bug, with no plan |
| [Plan an epic](epics.md) | plan work too big for one pull request |
| [Stop a change or an epic](drop-work.md) | drop work you've decided not to ship, and record why |
| [Work with a team](teams.md) | plan with teammates, whether or not they use LETS |
| [Plan across several repos](several-repos.md) | share one planning repo between repos that make one product |
| [Move plans to another home](move-plans.md) | move a repo's plans, say from `plans/` in the repo to a planning repo |
| [Use the same settings on two computers](settings-on-two-computers.md) | carry your profile and settings to another computer |
| [Add your own steps to a command](additions.md) | change how a command works for you, without editing LETS (`/lets:add`) |
| [Track changes as issues](issues.md) | create GitHub or GitLab issues that point at your plans |
